# Simulados do TSE

Participar dos simulados oficiais do TSE (set/2026) — gera dados sintéticos para validar o pipeline ponta-a-ponta com dados realistas.

## Pré-requisitos

- Cadastro como "interessado na divulgação" aprovado (resolução TSE vigente para o pleito 2026 — ver [reference/regulatory.md](../reference/regulatory.md)).
- Pipeline `/api/ingest` operacional com retry/dedup.
